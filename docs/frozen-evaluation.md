# 冻结评价报告

## 结论

这套冻结策略**没有实现“2015 年至今每年跑赢 SPY 10 个百分点”**。

- 正式证据状态：`UNVERIFIED`。
- QuantConnect 结构化年度门槛：`FAIL`；基础组 12 个评价期全部未达到 `SPY + 10`。
- 组合安全门槛：两组均为 `PASS`；没有保证金追缴或警告，没有无效订单，峰值总名义敞口低于 `2.00x`。
- 未验证原因：两组回测生成了 2,931 个每日证据行和 466/452 个因果审计样本，但写入 QuantConnect Object Store 时均失败，保存字节数为 0。Atlas 因此无法独立重算逐年权益、最大回撤，也无法逐条检查严格因果样本。

基础组从 100 万美元增长到 `4,253,426.26` 美元，累计回报约 `325.34%`；同一年度统计隐含的 SPY 累计总回报约 `274.29%`，基础组累计领先约 `51.04` 个百分点。这只说明累计结果较高，不能替代“每年领先 10 个百分点”的逐年标准。

## 可验证内容与缺口

Atlas 已通过只读 QuantConnect API 归档两组的完整回测响应、所有分页订单和所有分页已平仓交易。独立脚本重新解析年度统计并计算 `strategy - SPY` 与 `strategy >= SPY + 0.10`：两组各 12 行全部与平台状态一致。订单行数与平台汇总一致，两组都没有状态码为无效的订单，也没有订单成交时间或已平仓交易时间倒置。

这些检查不能替代缺失的每日证据对象。以下项目仍不可独立验证：

- 从每日权益重算 12 个年度回报和最大回撤，并与平台在 `0.01` 个百分点内对齐；
- 逐日持仓、保证金、风险贡献、费用和权益守恒；
- 查看至少 10 个 `data_cutoff < signal_time < order_time < fill_time` 的完整样本内容。

因此本轮不能发布正式 `FAIL` 或 `PASS`，只能发布 `UNVERIFIED`；同时，现有平台年度统计清楚显示策略没有达到收益目标。
